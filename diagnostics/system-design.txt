Data points:
    Task arival rate (current + graph)
    Deadline hit rate (current + graph)
    Average processing time (current + graph)

    List of online nodes (Node name, Assigned Tasks, CPU%, Memory%)
    List of tasks the system can run (Task name, average processing time)

API every x seconds and will cache the data. The web server will then display this data

    global average processing time
